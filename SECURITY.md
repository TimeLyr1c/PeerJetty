# Security reporting / 安全反馈

Report vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/TimeLyr1c/PeerJetty/security/advisories/new). This repository has enabled that feature. Do not post exploit details, private keys, trust records, configuration or personal files in public Issues.

The current supported release is 1.0.0. Include version/build, macOS version, impact and minimal reproduction steps using disposable identities and fictional files. PeerJetty uses TLS 1.3 and its own pairing protocol; it has not undergone an independent security audit. Text history is local and not encrypted by the app. See [protocol limitations](Docs/PROTOCOL.md) and [text privacy](Docs/TEXT.md).

请通过已启用的 [GitHub 私密漏洞报告](https://github.com/TimeLyr1c/PeerJetty/security/advisories/new)反馈安全问题。不要在公开 Issue 发布漏洞利用细节、私钥、信任记录、配置或私人文件。

当前支持版本为 1.0.0。报告请提供版本／构建号、macOS 版本、影响与最小复现步骤，使用隔离身份及虚构文件。应用使用 TLS 1.3 和本项目的配对协议，尚未经过独立安全审计；文本历史在本机保存，未由应用加密。限制见上述协议与隐私文档。
