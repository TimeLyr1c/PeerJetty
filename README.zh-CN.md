# PeerJetty

让你的 Mac 之间更方便地交接文件。配对一次、设置默认目标，之后把文件拖到屏幕顶部，即可通过局域网发送。

[English](README.md) · **简体中文**

## 功能

- 两台 Mac 安装同一个原生应用，支持双向传输。
- 自动发现附近设备，首次配对时在两台屏幕核对六位校验码。
- 拖拽或使用文件选择器发送文件与文件夹。
- 已信任设备自动接收，默认只通知；每台接收电脑可单独开启收到后自动打开。
- 文件直接通过 TLS 1.3 传输，保存前校验完整性；同名文件自动添加后缀，不覆盖已有文件。

PeerJetty 面向固定工作设备之间的频繁文件交接，不宣称比 AirDrop 更快。

## 安装

当前安装包支持 **Apple Silicon（M 系列）Mac，macOS 15 或更高版本**。PeerJetty 0.3.2 支持简体中文和英文，可在应用设置里选择“跟随系统 / 简体中文 / English”，退出重开后生效。

1. 前往 [Releases](https://github.com/TimeLyr1c/PeerJetty/releases/latest)，从 **Assets** 下载 DMG。
2. 打开镜像，将 `PeerJetty.app` 拖入 `Applications`，然后推出镜像。
3. 在两台 Mac 上打开应用。它运行在菜单栏中，默认不显示 Dock 图标。

当前应用采用本地 ad hoc 签名，**尚未经过 Apple 公证**。macOS 可能阻止首次运行，请先核对下载来源，再使用系统设置 → 隐私与安全性提供的打开选项。

更新时先退出应用，在 Applications 中替换后重新打开。正常更新保留配对与设置。从 OpenOnMini 升级时，请先退出旧应用，避免同时运行两个版本。

## 配对与发送

1. 将两台 Mac 接入同一局域网，并保持应用运行。
2. 各自设置设备名称与接收目录，保存初始化设置；系统询问时允许局域网访问。
3. 两台电脑都点击 **添加设备 · 2 分钟**，选中另一台设备后点击 **连接 / 配对**。
4. 核对两台屏幕上的六位校验码，仅在一致时双方确认。
5. 将配对设备设为默认发送目标，然后把文件拖到屏幕顶部投放区，或使用文件选择器发送。

等待“对方已保存”的确认，才表示接收完成。已信任设备自动接收；**收到后自动打开** 默认关闭，每台接收电脑可单独开启。完整保存的文件由默认应用打开，文件夹在 Finder 中打开。

发现不到设备时，检查局域网权限和 Wi-Fi 设备隔离。也可使用设置窗口显示的地址与端口手动连接，仍需通过相同的配对校验。更换设备后重新配对，并移除旧设备的信任；不要复制或同步设备私有身份。

## 文本（0.4.0 源码／测试版）

菜单栏“发送文本…”打开多行输入面板，选择已配对设备，输入或粘贴后按 ⌘Enter 发送。接收文本可查看并主动复制，不自动覆盖剪贴板或打开链接。两端需要支持文本，旧版仍可传文件。

成功收发的文本**始终在各自 Mac 上保存**。设置可隐藏历史入口，隐藏不会停止记录；默认保留最近 500 条，可改为最近 30 天或一直保留。详见 [文本使用与隐私](Docs/TEXT.md)。当前公开的 0.3.2 安装包不含此功能，0.4.0 为本地测试候选。

## 分类设置（0.4.0 源码／测试构建）

设置采用原生顶部五分类：通用、设备、传输、文本、关于。选择分类查看对应选项，小屏幕可纵向滚动。本机名称仍需点击保存，开关沿用原有保存行为；切换分类不会丢失尚未保存的名称。

## 支持范围与隐私

- 仅支持局域网，两端必须在线且处于唤醒状态。不使用云端中转、SSH、账号或写死在源码中的设备凭据。
- 应用在设置和菜单栏提供手动“检查更新”，详见 [更新说明](Docs/UPDATES.md)。Windows 客户端、自动安装更新、离线队列和断点续传尚未实现；中断后需要重新发送。
- 应用在有／无刘海屏幕上，拖到菜单栏下方、屏幕上方中央即可提前出现静止卡片，无需碰到真实顶边。详见 [显示适配与验收清单](Docs/DISPLAY-PLAN.md)。
- 配置位于 `~/Library/Application Support/PeerJetty/`，私有身份保存在本机钥匙串中；不要通过 Git 或云同步共享这些内容。
- 文本历史位于 `~/Library/Application Support/PeerJetty/TextHistory/history.sqlite`，仅当前用户可访问，与源码／安装包分开，请勿通过 Dropbox 或 Git 同步。
- 配对协议由本项目实现，尚未经过独立安全审计。详见 [协议文档](Docs/PROTOCOL.md)。

## 从源码构建

需要 macOS 15+、带有 Swift 5.9+ 与 macOS 15+ SDK 的 Command Line Tools 或 Xcode、Python 3，以及系统 OpenSSL。没有第三方 Swift 包依赖，也不需要 Homebrew 运行环境。

```sh
git clone https://github.com/TimeLyr1c/PeerJetty.git
cd PeerJetty
./build.sh
```

产物为 `outputs/PeerJetty.app`。构建架构跟随本机，脚本不会生成通用二进制；Intel 构建尚未经过实机验证。
