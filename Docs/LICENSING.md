## 对使用者意味着什么

MIT 允许使用、复制、修改、分发、再许可和商业销售，包括闭源衍生产品。分发软件的副本或实质性部分时，需要保留适用的版权与许可声明。MIT 不要求修改版继续开源，也不要求向本仓库提交 PR；软件按原样提供，不作条款中列明的保证。

正式 LICENSE 保留标准 MIT 全文，没有另加禁止商用、强制署名宣传或强制开源等条件。

## 发布时怎么处理

- 源码仓库保留根目录 LICENSE；保留已有、适用的第三方版权与许可声明。
- 分发安装包时也随包提供适用的许可声明。
- README 链接 LICENSE；GitHub 上传现有仓库时不再另生成一份许可证。
- 仓库名称、应用名称与 GitHub Contributor 状态不改变上述许可条件或版权归属。
